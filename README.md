# Portfolio Personal de Ignacio Padrón

Este repositorio contiene el código fuente de mi sitio web personal/portfolio profesional, donde muestro mis habilidades, experiencia y proyectos en el ámbito de SysAdmin, DevOps y Ciberseguridad.

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura del sitio
- **CSS3**: Estilos y diseño responsivo
- **JavaScript**: Interactividad y gráficos
- **Chart.js**: Visualización de habilidades mediante gráficos
- **Font Awesome**: Iconos
- **Formspree**: Gestión del formulario de contacto

## 📋 Características

- Diseño responsivo para todos los dispositivos
- Secciones organizadas de información personal y profesional
- Visualización interactiva de habilidades técnicas y profesionales
- Portfolio de proyectos con enlaces a documentación detallada
- Formulario de contacto funcional
- Optimización de rendimiento y SEO

## 🔧 Instalación y Despliegue

1. Clona este repositorio:
   ```
   git clone https://github.com/ignaciopadron/ignaciopadron.es.git
   ```

2. Navega al directorio del proyecto:
   ```
   cd ignaciopadron.es
   ```

3. Abre el archivo index.html en tu navegador para visualizar el sitio localmente, o súbelo a tu servidor web preferido.

## 📁 Estructura del Proyecto

```
/
├── index.html              # Página principal
├── css/                    # Estilos CSS
│   └── style.css           # Archivo principal de estilos
├── js/                     # Scripts JavaScript
│   └── script.js           # Funcionalidades interactivas
├── img/                    # Imágenes del sitio
├── assets/                 # Otros recursos
│   └── docs/               # Documentos descargables
└── README.md               # Documentación del proyecto
```
